# 作業区分「サンプル」の説明書き

現場・管理者向け、両方の説明です。読むのに5分かかりません。

---

## 1. 現場向け: 作業区分「サンプル」の選び方（3ステップ）

サンプル・見本づくりの作業は、量産とは別の区分「サンプル」で記録します。
**量産の合間にちょっと手伝った時間**も、その時間だけサンプルで記録してください。

### 入れ方（3ステップ）

1. 作業記録の画面で、品番を選ぶ前に **「区分」で「サンプル」を選ぶ**
2. 出てくる一覧から、**サンプル案件**（自分のチームでなくてもOK・全チーム分から選べます）を選ぶ
3. **作業時間（必須）** を入れる。できた点数がわかれば「仕上がった点数（任意）」にも入れる

工程表・工程以外チェックはサンプルには出ません。時間（と、わかれば点数）だけで記録が終わります。

### よくある質問

**Q. サンプルは自分のチームの案件しか選べない？**
いいえ。サンプルはチーム関係なく、進行中の案件がすべて出ます。

**Q. 点数は必ず入れないといけない？**
いいえ、任意です。作業時間だけでも記録できます。

**Q. 区分を間違えて記録してしまった**
リーダー・管理者に相談してください（枚数修正と同じく、記録の消し直しで直します）。

## 2. 管理者向け: 価値の計上ルール

### サンプル代の按分

サンプル1案件の「サンプル代合計」（＝サンプルマスターの単価 × 枚数）を、
**その案件に関わった全員の作業時間の比率で按分**します。

```
Aさん 3時間・Bさん 5時間で作業した、サンプル代合計 ¥24,000 の案件の場合

Aさんの取り分 = ¥24,000 × 3 / (3+5) = ¥9,000
Bさんの取り分 = ¥24,000 × 5 / (3+5) = ¥15,000
```

按分額の合計は必ずサンプル代合計と一致します（円未満の端数は残ります。丸めは画面表示のときだけ）。

### 無償サンプルは0円で計上

サンプルマスターで「無償サンプル（請求なし）」にチェックが入っている案件は、
単価が入っていても **生産価値は常に0円** として計上します。時間だけは記録されます
（＝その分「1時間あたり」は下がって見えます。無償で作業した実態そのままです）。

### 2026/10/1から開始・過去には遡らない

作業区分「サンプル」の記録は **2026年10月1日から**です。それより前の期間を
「数字を見る」で見たときは、サンプルの数字は0のまま出ます（過去の記録を
あとから区分し直すことはしません）。2026/10/1より前を含む期間を見ているときは、
画面にその旨の注記が出ます。

## 3. 確認手順（デプロイ後）

1. 作業記録の画面で、区分「サンプル」→ 案件を選択 → 作業時間を入れて記録する
2. 画面を再読み込みして、記録した内容がそのまま残っていることを確認する
3. 「数字を見る（管理者向け）」を開き、対象メンバーの行に「うちサンプル」「サンプル比率」
   「量産のみ円/h」の数字が出ていることを確認する

もし手順2で **記録した区分（サンプル/量産の別）が再読み込み後に消えている・量産に
戻ってしまう**場合、GAS（Google Apps Script）側の保存処理を直す必要があります。
このアプリの日報レコードはGAS側でJSONをそのまま受け渡ししている想定のため、
新しく増えた `kubun`・`sampleQty` のフィールドも特別な変更なくそのまま保存される
はずですが、**これはコード側からの推測であり未確認です**。もし保存されない場合は、
GASの `doPost` 等でレコードの列・フィールドを決め打ちで扱っていないか確認してください。
